# 家計4象限 × ライフプラン表

支出を「毎月／不定期」×「固定／変動」の4象限に分けて洗い出し、
その年間支出から100歳までの資産推移を計算するライフプランツールです。

ブラウザだけで動きます。サーバーもログインも不要です。

## できること

- **家計の4象限** — 支出を毎月固定費／毎月変動費／不定期固定費／不定期変動費に分類
- **手取りの使われ方** — 収入に対する支出の内訳と貯蓄率を一本の帯で表示
- **3つの資産** — 現預金・国債・株式などを分けて管理。取り崩しは国債が先、株式が後
- **ライフイベント** — 期間指定に対応（教育費や仕送りのように何年も続く支出）
- **相続・臨時収入** — 複数登録可。「相続を除いて計算」で相続なしの場合も検証できる
- **子どもへの贈与** — 夫婦の資産とは別枠で複利計算。贈与分は夫婦側の支出として差し引き
- **削減インパクト** — 毎月いくら減らすと最終資産がどれだけ変わるかを試算

## 使い方

1. 収入（手取り）を入力
2. 支出を4象限に分けて入力
3. 前提条件（年齢・退職年齢・年金・利回り・物価上昇率など）を設定
4. ライフイベントと相続を登録
5. 資産推移のグラフと年次キャッシュフロー表を確認

入力内容は自動でブラウザに保存されます（localStorage）。
別の端末へ移すときは「JSONで書き出す」「JSONを読み込む」を使ってください。

## プライバシー

入力したデータは**お使いのブラウザの中にのみ保存**され、外部には一切送信されません。
サーバーへの通信もありません。ブラウザのデータを消すと入力内容も消えます。

## 計算の前提

- 収入は手取りで入力する前提のため、税・社会保険料は別途計算していません
- 運用益への課税を計算します（前提条件でオン／オフを切り替え）。投資に回したお金はNISAの枠から先に埋まり、枠を超えた分は課税口座として扱います。課税されるのは**売却したときだけ**で、含み益のまま持っている間は課税されません。取り崩しは課税口座から先に行います
- 最終年の資産には、まだ売っていない含み益への将来の税が含まれたままです
- ライフイベントと生活費は物価上昇に連動、相続・贈与は名目固定
- 現預金の上限を超えた分は株式などへ、不足したときは国債→株式の順に取り崩し

簡易モデルです。重要な判断は必要に応じて専門家にご相談ください。
